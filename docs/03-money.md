# 03. 돈과 재테크

숫자(금액, 비율, 확률)는 전부 밸런스 단계에서 정한다. 여기는 규칙만.

## 월급
- **턴마다 자동 지급**. 💰 칸은 보너스
- 이유: 횟수 고정 구조에서 '월급 칸을 지날 때 지급'이면 주사위 숫자 큰 사람이 월급을 더 받음

## 세금
- 월급 받을 때 일정 비율 자동 공제 (고소득일수록 많이)
- 가끔 '세금 안 내기' 기회 → **플레이어가 직접 선택** (복권처럼 유혹 구조)
  - 안 내기로 하면 운세로 결과: 좋으면 면제 / 나쁘면 세무조사로 세금 + 벌금

## 보험 (3종, 살 수 있는 상품)
- 🏥 **건강보험**: 병원비, 사고
- 🏠 **재산보험**: 집을 살 때·가지고 있을 때 대비. 집이 있으면 이득
- 🚗 **자동차보험**: 자동차를 산 뒤에만 가입
- 보험료는 매 턴 조금씩 빠짐
- 매 턴 해지 가능. 해지하면 몇 턴 동안 재가입 불가
- 맞는 보험이 있으면 그 사고에서 돈을 돌려받음 (운세의 '보험형' 결과와 연결 — `04-luck.md`)

## 대출
- 언제든 은행에서 빌림, 매 턴 이자
- 한도: 좋은 직업·집·차가 많을수록 많이, 백수는 적게
- 빌릴 때 상환 기한(턴 수). 오래 방치하면 **강제 청산** 이벤트
- 끝날 때 남은 빚은 자산에서 뺌

## 마이너스 자산
- 나쁜 이벤트로 강제로 돈을 내야 하는데 모자라면 **일시적으로 마이너스**
- 갚으면 원래대로
- 마이너스인 동안 매 턴 확률로 나쁜 이벤트 (운세로 커버 가능)

## 상점
- **칸이 아니라 길 위의 지나가는 지점** (원작 월급날처럼)
- 지나가면 살지 말지 고르고, 멈추지 않고 남은 칸만큼 계속 이동
- 파는 것: **집, 자동차, 소개팅 회사 회원권**
- 집과 자동차는 상점에서만 살 수 있음
- 단계마다 몇 군데 둘지는 보드 그릴 때

## 자동차
- 등급: 🛵 스쿠터 / 🚗 일반차 / 🏎️ 고급차. **1인 1대**
- 혜택: 주사위 결과 **±1 조정** (원하는 칸에 멈추기)
- 사용 방식 (2026-10-15 변경): **던지기 전에** 능력을 쓸지 정함 → 쓰면 그 자리에서 1번 차감 → 주사위가 나오면 -1 / +0 / +1 중 고름. **주사위 1이면 +0, +1만**
- 사용 횟수: 단계마다 충전. 차를 바꿔도 이번 단계에 쓴 횟수는 이어짐

| 차 | 청년 | 중년 | 노년 |
|---|---|---|---|
| 스쿠터 | 1 | 2 | 3 |
| 일반차 | 2 | 3 | 4 |
| 고급차 | 3 | 4 | 5 |

- 고급차 추가 혜택: 행복 보너스 + 배우자 등급 확률 소폭 상승
- 구매: 상점에서 **중년까지만**. 노년엔 못 사지만 갖고 있던 차는 계속 사용
- 단점: 매 턴 유지비 / 차 있는 사람만 교통사고 이벤트 / **노년엔 사고 확률 상승**
- 결정 이유
  - 매 턴 ±1은 3칸 중 고르는 셈이라 나쁜 칸을 거의 다 피함 → 차가 필수가 되고 위기·보험·운세가 무력해짐 (사용자 지적)
  - '차 산 뒤 총 5번'은 차를 다시 사면 초기화되는 문제 → 횟수를 차가 아닌 단계에 묶음

## 복권과 도박중독
- 성인(청년)부터 매 턴 자기 차례에 구매 가능
- 당첨 여부는 **다음 자기 턴**에 확인
- 중독 확률 (= 다음에 살 때 중독될 확률)
  - 10%에서 시작, 살 때마다 +5%, 상한 50%
  - 안 사고 넘긴 턴마다 -10%, 하한 10%
  - 예) 3번 연속 구매(10·15·20%) → 다음 25% → 한 턴 쉬면 15% → 또 쉬면 10%
- 중독되면 매 턴 일정 확률로 나쁜 이벤트
- 치료 가능 (병원 칸, 상담 이벤트, 돈 지불 등)
- 미정(밸런스): 가격, 당첨 확률, 당첨금, 중독 시 나쁜 이벤트 확률, 치료 비용

## 주식
- 성인(청년)부터. **매 턴 자기 차례에 자유 매매**
- 종목 5개 이내, 서로 다른 분야 (생명, IT, 화학, 의료, 엔터 등)
- 가격은 **모두에게 같음**
- 변동: 매 바퀴 랜덤 + 가끔 **뉴스** 이벤트 (예: "신약 임상 성공" 의료 +80%, "아이돌 열애설" 엔터 -40%)
- **플레이어 행동도 영향**: 누가 아이돌 데뷔 → 엔터 상승, 사업가 망함 → 그 분야 하락, 배우자 스캔들 → 배우자 분야 하락 (`05-marriage.md`)
- 운세 연결: 좋은 운세면 다음 뉴스 힌트 (`04-luck.md`)
- 미정: 배당
