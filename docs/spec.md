| 항목 | 결정 | 문서 |
|---|---|---|
| 플랫폼 | 웹 먼저 (폰 브라우저 대응, PWA). 앱은 나중에 Capacitor로 포장 | — |
| 인원 | 최대 4명. 자리마다 사람 또는 AI 선택 | — |
| 솔로 모드 | 나 + AI 1~3명. AI는 규칙 기반 봇 (LLM 아님) | — |
| 같이 하기 | 1단계: 한 기기 돌려가며 → 2단계: 온라인 방 (나중에) | — |
| 1차 목표 | 솔로(AI) + 한 기기 멀티 | — |
| 설계 원칙 | 규칙 엔진은 하나. 조작 주체(사람/AI/온라인)만 바꿔 끼운다 | — |
| 플레이 시간 | 4인 기준 30분~1시간 | 01 |
| 게임 길이 조절 | 시작 나이로 고름: 1살부터(긴 판) / 성인부터(짧은 판) | 01 |
| 인생 단계 | 어린이 / 학생 / 청년 / 중년 / 노년 | 01 |
| 진행 구조 | 어린이~중년은 단계별 룰렛 횟수 고정 → 다 같이 다음 단계. 노년만 골까지 경주 | 01 |
| 종료 조건 | 노년 단계에서 모두 골에 도착하면 종료 | 01 |
| 룰렛 | 1~6 | 01 |
| 길 모양 | 단계별 긴 길. 갈림길·이벤트 맵 입구. 단계 끝은 휴식 칸 | 01 |
| 갈림길 | 직접 선택 + 조건(능력치·돈). 단계 안에서 다시 합쳐짐 | 01 |
| 이벤트 맵 | 옆길형 + 별도 화면형 | 01 |
| 승리 조건 | 최종 점수 = 자산 점수 + 행복 점수 | 01 |
| 능력치 | 지력 / 체력 / 매력, 0~10 | 02 |
| 직업 | 10~12개. 승진(꾸준형/대박형). 조건 미달이면 백수 → 전직 | 02 |
| 월급 | 턴마다 자동 지급 (💰 칸은 보너스) | 03 |
| 세금 | 월급에서 자동 공제. 탈세 기회(직접 선택) → 운세로 면제 또는 세무조사 | 03 |
| 보험 | 건강 / 재산 / 자동차. 매 턴 보험료, 해지 자유(해지 후 몇 턴 재가입 불가) | 03 |
| 대출 | 언제든. 한도는 직업·재산 따라. 상환 기한 넘기면 강제 청산 | 03 |
| 마이너스 자산 | 일시적 마이너스 허용. 그동안 매 턴 확률로 나쁜 이벤트 | 03 |
| 상점 | 칸이 아니라 지나가는 지점. 집·차·소개팅 회원권 구매 | 03 |
| 자동차 | 스쿠터/일반차/고급차. 룰렛 ±1을 단계마다 1~5번. 중년까지만 구매 | 03 |
| 복권 | 성인부터 매 턴. 살수록 도박중독 확률 증가 | 03 |
| 주식 | 성인부터, 매 턴 자유 매매. 5종목 이내 분야별. 뉴스·플레이어 행동으로 변동 | 03 |
| 운세 | 최악~대대길 6단계. 매 턴 뽑기. 나쁜 일 결과를 바꾸고, 좋으면 주식 힌트 | 04 |
| 결혼 | 배우자 속성 4개(외모·재력·명성·성격) + 등급 5단계 + 직업 분야 태그. 재혼 없음 | 05 |
