## 확정 요약

| 항목 | 결정 | 문서 |
|---|---|---|
| 게임 이름 | **데굴데굴 라이프** ("인생게임"은 해즈브로·타카라토미 이름이라 자체 이름 사용) | — |
| 배경 | 현실 같은 한국 동네가 기본. 나중에 가상 마을·테마 맵으로 확장 | — |
| 플랫폼 | 웹 먼저 (폰 브라우저 대응, PWA). 앱은 나중에 Capacitor로 포장 | — |
| 인원 | 최대 4명. 자리마다 사람 또는 AI 선택 | — |
| 솔로 모드 | 나 + AI 1~3명. AI는 규칙 기반 봇 (LLM 아님) | — |
| 같이 하기 | 1단계: 한 기기 돌려가며 → 2단계: 온라인 방 (나중에) | — |
| 1차 목표 | 솔로(AI) + 한 기기 멀티 | — |
| 설계 원칙 | 규칙 엔진은 하나. 조작 주체(사람/AI/온라인)만 바꿔 끼운다 | — |
| 플레이 시간 | 4인 기준 30분~1시간 | 01 |
| 게임 길이 조절 | 시작 나이로 고름: 1살부터(긴 판) / 성인부터(짧은 판) | 01 |
| 인생 단계 | 어린이 / 학생 / 청년 / 중년 / 노년 | 01 |
| 진행 구조 | 어린이~중년은 단계별 주사위 횟수 고정 → 다 같이 다음 단계. 노년만 골까지 경주 | 01 |
| 종료 조건 | 노년 단계에서 모두 골에 도착하면 종료 | 01 |
| 주사위 | 1~6 | 01 |
| 길 모양 | 단계별 긴 길. 인생 갈림길·이벤트 길 갈림길. 단계 끝은 휴식 칸 | 01 |
| 갈림길 | 큰 선택은 길이 갈라졌다 합쳐짐(어린이 학원/놀이, 청년 대학/취업, 중년 창업/회사, 노년 도시/시골). 나머지는 정지 칸에서 선택만 | 01 |
| 이벤트 길 | 단계마다 1개, 중간쯤 갈림길에서 선택, 15칸 이내, 조금 앞에서 합류. 칸마다 미니게임, 한 가지에 치중(운동회·두뇌 올림피아드·축제 거리·카지노·세계일주). 능력치↑ → 미니게임 쉬워짐 | 11 |
| 승리 조건 | 최종 점수 = 자산 점수 + 행복 점수 | 01 |
| 능력치 | 지력 / 체력 / 매력, 0~10. 청년·중년에도 오르내림, 능력치 대회 이벤트 | 02 |
| 직업 | 14개 + 백수 (과학자·사업가는 분야를 고름). 꾸준형 3단계 자동 승진 / 대박형 커리어 주사위. 조건은 취업 때만 봄. 대학/취업은 **청년 맨 처음(20세)** 갈림길에서 고름 → 대학 길(수능·능력치·학자금 대출) / 취업 길을 지나 직업 선택 | 02 |
| 월급 | 턴마다 자동 지급 (💰 칸은 보너스) | 03 |
| 세금 | 월급에서 자동 공제. 탈세 기회(직접 선택) → 운세로 면제 또는 세무조사 | 03 |
| 보험 | 건강 / 재산 / 자동차. 매 턴 보험료, 해지 자유(해지 후 몇 턴 재가입 불가) | 03 |
| 대출 | 언제든. 한도는 직업·재산 따라. 상환 기한 넘기면 강제 청산 | 03 |
| 마이너스 자산 | 일시적 마이너스 허용. 그동안 매 턴 확률로 나쁜 이벤트 | 03 |
| 상점 | 칸이 아니라 지나가는 지점. 집·차·소개팅 회원권·반려동물·찬스 카드 | 03 |
| 자동차 | 스쿠터/일반차/고급차. 주사위 ±1을 단계마다 1~5번. 중년까지만 구매 | 03 |
| 복권 | 성인부터 매 턴. 살수록 도박중독 확률 증가 | 03 |
| 주식 | 성인부터, 매 턴 자유 매매. 5종목 이내 분야별. 뉴스·플레이어 행동으로 변동 | 03 |
| 운세 | 최악~대대길 6단계. 매 턴 뽑기. 나쁜 일 결과를 바꾸고, 좋으면 주식 힌트 | 04 |
| 연애 | 여러 명 호감도 동시에. 데이트 칸 + 소개팅 회사(직접 해지, 결혼하면 자동 해지) | 05 |
| 결혼 | 결혼 지점 청년 2·중년 1 (지나가면 이벤트). 호감도 50%↑ 중 고백, 호감도 비례 성공. 청년 결혼만 자녀 가능 (결혼하자마자 한 번 묻고, 그 뒤 데이트 칸에서도). 식장 3단계. 중년 결혼식장 뒤에는 데이트 칸 없음 | 05 |
| 배우자 | 속성 4개(외모·재력·명성·성격) + 등급 별 1~5개(★~★★★★★) + 직업 분야 태그 | 05 |
| 자녀 | 출산은 청년 결혼자만 청년 안에서. 중년엔 입양(1번) | 05 |
| 반려동물 | 청년·중년. 매 턴 행복↑, 사료값·사고·사망 시 행복↓ | 05 |
| 플레이어끼리 | 중간 수준. 축의금(식장 단계 따라 랜덤), 돈 빌려주기(청년~, 상대마다 1번, 떼이면 법적 공방, 안 갚으면 소송 결과와 상관없이 신용불량), 방해 카드(역풍), 같은 칸 만남(전원 참여. 청년·중년 미니게임 꼴찌가 잃고 1등이 얻음, 나머지는 운세 이벤트) | 06 |
| 화면 | 시안 D: 위에 기본 정보만, 아래는 **보드 세계 안**(캐릭터 등 뒤 시점, 길가에 건물). 내 말 주변 앞 6칸 이상, 전체 지도 버튼. 남의 차례는 그 사람 화면을 그대로 관전 | 09 |
| 카드 | 즉시(선택 카드·다 같이 카드 포함, 단계별 더미) / 방해 / 찬스. 방해·찬스는 1장씩만 보유(새로 얻으면 둘 중 고름). 방해는 상점에서 안 팖 | 07 |
| AI | 성격 5종(재테크·엘리트·가족·도박꾼·안전) 랜덤 배정·공개·중복 가능. 성격별 말풍선 대사. 난이도 3단계(반칙 없음). 속도는 설정, 기본 '빠르게+큰 일만 연출' | 08 |
| 이혼 | 중년부터. 행복↓, 효과 사라짐, 재산 분할(재력 비교), 위자료는 잘못한 쪽(사건으로 판정). 양육비 없음. 중년 결혼 지점 전 이혼이면 재결합·새 결혼 가능 | 05 |
