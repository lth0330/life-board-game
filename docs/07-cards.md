# 07. 카드 (주제 6)

## 종류
| 종류 | 사용 | 예시 |
|---|---|---|
| ⚡ 즉시 카드 | 뽑자마자 효과, 손에 안 남음 | 지갑 주움 +50만, 감기 병원비 |
| 😈 방해 카드 | 들고 있다가 상대에게 | 소송, 소문, 주가 루머, 연애 방해 (`06-players.md`) |
| 🍀 찬스 카드 | 들고 있다가 나에게 | 룰렛 다시 돌리기, 방해 막기, 운세 한 단계↑, 상점 할인 (초안) |

## 얻는 법
- 즉시 카드: 🎴 이벤트 칸에 멈추면 1장
- 방해·찬스 카드

| 얻는 곳 | 방해 | 찬스 |
|---|---|---|
| 🎴 이벤트 칸 (더미에 가끔 섞임, 예: 10장 중 1~2장) | ✅ | ✅ |
| 🏪 상점 지점 (돈으로 구매) | ❌ | ✅ |
| 🎮 미니게임 승리 (진 사람 카드 뺏기 또는 새 카드) | ✅ | ✅ |
| 🛋️ 휴식 칸 보상 | ❌ | ✅ |
| 🚪 이벤트 맵 보상 | ✅ | ✅ |

- 방해는 상점에서 안 팖: 부자가 방해 카드를 쓸어 담는 것을 막으려고. 방해는 운·실력으로만

## 보유 제한
- **방해 1장, 찬스 1장**까지
- 이미 있는데 같은 종류를 또 얻으면: 새 카드와 가진 카드 중 **하나를 골라 보유**, 나머지는 버림

## 미정
- 즉시 카드 안에 선택 카드를 넣을지
- 카드 더미를 단계별로 나눌지
- '다 같이' 카드를 넣을지
- 찬스 카드 목록
