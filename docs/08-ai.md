# 08. AI (주제 9)

- 규칙 기반 봇 (LLM 아님). 사람과 같은 정보로만 판단 (미래 뉴스·숨은 특성 등 못 봄)

## AI가 판단할 것
갈림길, 복권, 주식 매매, 대출, 보험 가입·해지, 연애 상대·데이트, 고백 여부, 결혼식장 단계, 출산·입양·반려동물, 방해 카드 대상, 찬스 카드 사용 시점, 돈 빌려주기 수락, 탈세 여부, 자동차 ±1, 미니게임

## 성격 (5종)
| 성격 | 행동 |
|---|---|
| 💰 재테크형 | 주식·대출 적극, 돈 되는 쪽 선택 |
| 📚 엘리트형 | 공부·대학·고소득 직업, 명성·재력 높은 배우자 선호 |
| 😊 가족형 | 결혼·자녀·반려동물, 성격 좋은 배우자, 행복 우선 |
| 🎲 도박꾼형 | 복권 자주(중독 위험), 위험한 선택·방해 적극 |
| 🛡️ 안전형 | 보험 다 들고 빚 싫어함, 위험한 투자 거절 |

- 게임 시작 때 **랜덤**으로 배정, 성격은 **화면에 보여줌**
- 같은 성격 **중복 가능** (도박꾼 셋인 판도 그대로)

## 난이도
- **쉬움 / 보통 / 어려움**
  - 쉬움: 가끔 엉뚱한 선택, 미니게임 약함
  - 어려움: 확률을 잘 따지고 방해 카드를 1등에게 씀, 미니게임 강함
  - 어려움도 반칙 없음

## AI 차례 속도
- 설정에서 사용자가 고름 (빠르게 / 보통 / 천천히). 기본값: **빠르게**. 결혼·복권 당첨·이혼 같은 큰 일은 속도와 상관없이 배너·축하 연출이 나옴

## 말풍선 대사
- 큰 일이 있을 때 **성격에 맞는 한마디** (같이 노는 사람처럼)
  - 도박꾼형 복권 구매: "이번엔 진짜 느낌 왔다"
  - 안전형 보험금 수령: "거봐, 들어 두길 잘했지"
  - 방해당함: "기억해 두겠어…"
- 대사 문구는 콘텐츠 작업 단계에서 작성

## 재테크형 AI가 꼴찌인 이유 (2026-10-15 점검, 300판)
| | 재테크형 | 다른 성격 |
|---|---|---|
| 총점 | 97 | 145~216 |
| 자녀 | **0명** | 0.4~0.9명 |
| 반려동물 | **0%** | 89~100% |
| 집 | **2%** | 13~65% |
| 결혼 | 32% | 26~75% |
| 주식 손익 | **-7만** | +41~52만 |
| 은행 대출 (끝날 때) | **820만** | 13~262만 |
| 행복 | 32 | 49~98 |

원인 (코드 `ai.ts`)
1. 아이 낳기 점수 0.5 vs 안 낳기 1.5 → 절대 안 낳음. 새 가족 칸에서도 '안 함' 3점, 상점 반려동물 0.8 vs 지나가기 2 → 행복 줄 곳이 없음
2. 주식을 무작위 분야로 돈의 25%씩 자주 사고, 130 넘을 때만 팜 → 떨어진 주식을 계속 들고 있음
3. 현금을 주식에 넣어서 월세·관리비로 돈이 마이너스 → 은행 대출(매 턴 이자 1%)이 쌓임 → 집도 못 삼
### 고친 것 (2026-10-15)
- 아이·입양·반려동물을 다른 성격처럼 고름
- 주식: 무작위로 사지 않고 운세 힌트가 있을 때만 (대대길 50%, 재테크형은 대길에도 15%). 현금 800만 + 월급 2턴치는 남김. 130 넘으면 팔고 75 밑이면 손절. 돈이 마이너스면 주식부터 팔아 메움
- 결과: 총점 97 → 114 (아직 꼴찌)

### 남은 진짜 원인: 창업이 모두에게 손해
- 재테크형이 창업을 안 하면 총점 114 → 180, 도박꾼도 172 → 204
- 이유: 중년 중간(새 가족 칸 뒤 갈림길)에서 2,000만(모자라면 빚)을 내고 창업 → 사업가 월급은 소기업이면 120만뿐이고, 커리어 주사위는 다음 단계 시작(=노년, 은퇴)에야 굴림 → 승진할 기회도 거의 없이 은퇴. 투자금을 돌려받을 길이 없음
- 창업 규칙을 고칠지 결정 필요
