# ChatGPT로 판·건물·사건 그림 만들기 (2026-11-03)

사용자 결정: **판·건물·나무·하늘·사건 창 그림은 사용자가 ChatGPT로**, 캐릭터·옷은 지금처럼 코드 그림을 Claude가 다듬음.
넣을 자리와 파일 이름·크기는 `14-images.md`. 이 문서는 **어떻게 만들고 넣는지**와 **요청 문장(프롬프트)**.

## 1. 순서 (한 번에 다 하지 말고 조금씩)

1. **기준 그림 1장**: `building-house`(우리 집)를 먼저 만든다. 마음에 들 때까지 다시 뽑기
2. 그 그림을 넣고 게임에서 본다 (Claude에게 "넣어 봤어" 하면 화면을 캡처해서 같이 봄). 캐릭터(코드 그림)와 어울리는지 확인
3. 괜찮으면 **같은 대화창에서** 기준 그림을 다시 올리며 나머지 건물 → 나무 → 땅·하늘 → 칸 그림 → 사건 그림 순서로
4. 테마(봄·여름·가을·겨울) 그림은 마지막에. 기본 그림에 "눈 덮인 버전으로" 처럼 요청

## 2. 그림체 맞추기 (가장 중요)

- 모든 요청 앞에 아래 **공통 문장**을 붙인다
- 새 대화를 열면 그림체가 달라지기 쉬움 → **기준 그림을 꼭 같이 올리고** "이 그림과 똑같은 그림체로"
- 한 장씩 따로 요청 (여러 개를 한 장에 그리게 하면 자르기 어렵고 크기가 들쭉날쭉)

### 공통 문장 (복사해서 쓰기)
```
보드게임용 일러스트. 장난감 같은 귀여운 입체 그림체.
진한 갈색 잉크 테두리(#2A2118, 굵고 일정하게), 밝고 따뜻한 색, 그림자는 한 단계만.
큰 면 위주로 단순하게: 잔무늬·벽돌·작은 장식은 거의 없이.
앞면·옆면·윗면이 살짝 보이는 3/4 시점(위에서 약간 내려다봄).
배경은 완전히 투명(PNG). 글자·로고·사람은 넣지 마.
```
- **기준 그림은 두 번째 집**(빨간 지붕, 크림색 벽, 꽃 화분 하나, 2026-11-03). 첫 번째 집은 너무 자세해서 판에서 혼자 튀었음 → 캐릭터 그림체에 맞춰 단순하게 (사용자: 캐릭터를 많이 높이기는 무리라 다른 그림을 조금 낮춤)

## 3. 파일로 만들기

1. ChatGPT에서 받은 PNG를 내려받기 (배경이 투명인지 확인: 흰 바탕이면 "배경을 투명하게 다시")
2. **크기 줄이기**: https://squoosh.app 에 끌어다 놓고 → 오른쪽 형식 **WebP**, 품질 80 → 'Resize'에서 `14-images.md`의 추천 크기 **2배**로 (예: 건물 440×456)
3. 파일 하나가 **200KB 안쪽**인지 확인
4. 이름을 표대로 바꿔서 (`building-house.webp`) `app/src/assets/art/` 폴더에 넣기
5. GitHub에 올리면 배포됨. 이름이 맞으면 그 그림, 없으면 코드 그림 그대로 → **하나씩 바꿔도 됨**
