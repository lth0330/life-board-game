# 01. 게임 구조

## 플레이 시간과 길이 조절
- 목표: 4인 기준 30분~1시간 (스위치판은 2시간이 넘어 너무 길었음)
- 계산 기준: 차례당 약 20초 → 4인 한 바퀴 약 80초
- 길이 조절: **시작 나이 선택**
  - 1살부터 (긴 판, 약 45분~1시간)
  - 성인(청년, 20세)부터 (짧은 판, 약 30분). 어린 시절 능력치를 랜덤으로 줄지 직접 고르게 할지는 미정
  - 참고: 타카라토미판에도 일생 모드 / 어른부터 모드 / 어린이만 모드가 있음

## 인생 단계
- 5단계 (타카라토미 7단계를 줄임. 단계마다 칸을 넉넉히 주려고)
- 나이 구간 (초안): 어린이 1~7 / 학생 8~19 / 청년 20~39 / 중년 40~59 / 노년 60~
- 모두 같은 나이로 함께 자람 (나이는 단계로 정해짐)

## 진행 구조와 종료 조건
- 어린이~중년: 단계마다 **주사위 횟수 고정**. 다 쓰면 다 같이 다음 단계로
- 노년: 골 지점까지 경주. 먼저 도착하면 일찍 끝나고 늦으면 더 굴림
- **종료: 노년 단계에서 모두 골에 도착하면 끝**
- 단계별 주사위 횟수 초안 (1인당): 어린이 4 / 학생 8 / 청년 10 / 중년 8 / 노년 골까지(평균 5)
  - 1살부터 약 35회 ≈ 45분, 성인부터 약 23회 ≈ 30분
- 검토했던 종료 후보: 모두 은퇴 칸 도착(원작) / 정해진 나이에 종료 / 첫 은퇴자 후 1바퀴 → 타카라토미 방식으로 확정 (사용자가 직접 플레이해 확인)

## 길과 주사위
- 주사위 **1~6** (1~10보다 만들 칸이 2/3로 줄고 숫자 하나의 무게가 커짐)
- 원래 룰렛으로 정했다가 **주사위로 변경** (2026-10-15): 보드 위에 던지면 굴러가서 숫자가 정해짐
- **긴 길** (원형 아님). 스위치판 리뷰의 '같은 이벤트 반복' 불만을 피하려고
- 단계 끝 마지막 칸은 **휴식 칸**: 먼저 닿으면 남은 횟수만큼 작은 보상(용돈, 능력치 +1 등)
- 본 길 칸 수 초안: 어린이 20 / 학생 40 / 청년 50 / 중년 40 / 노년 20 = 약 170칸 (횟수 × 3.5 × 여유 1.3)
- 보류한 안: '멀리 갈수록 좋은 칸' — 돈 많은 사람이 차로 더 앞서가는 눈덩이 효과 때문. 노년 골 경주에서만 차 +1 정도는 나중에 검토 가능

## 갈림길
- 종류: **직접 선택** + **조건**(능력치·돈 등). 운 갈림길은 없음
- 갈라진 길은 단계 안에서 **다시 합쳐짐**. 선택 결과는 길이 아니라 캐릭터(직업·가족·능력치)에 남김
- 단계별 큰 갈림길:

| 단계 | 갈림길 | 종류 |
|---|---|---|
| 어린이 | 학원 다니기 vs 실컷 놀기 | 선택 (지력 vs 매력·행복) |
| 학생 | 동아리: 공부 / 운동 / 예체능 | 선택 |
| 학생 | 대학 진학 vs 바로 취업 | 선택 |
| 청년 | 직업 선택 | 조건 (능력치) |
| 청년·중년 | 결혼 지점 (청년 2곳, 중년 1곳): 고백 vs 비혼 | 선택 (지나가면 자동 이벤트, `05-marriage.md`) |
| 중년 | 입양 / 반려동물 / 안 함 | 선택 (입양은 자녀 없는 기혼자만, 1번. 출산은 청년에서만) |
| 중년 | 이직·창업 vs 회사 버티기 | 조건 + 선택 |
| 노년 | 은퇴지: 도시 vs 시골 | 선택 (위험·보상 차이) |

## 갈림길 모양 (2026-10-15)
**A. 길이 갈라지는 갈림길** — 인생 방향이 크게 갈리는 선택. 5~8칸 갈라졌다가 다시 합쳐짐

| 단계 | 갈림길 | 길마다 다른 점 |
|---|---|---|
| 어린이 | 학원 길 / 놀이 길 | 학원: 성장(지력) 칸 / 놀이: 행복·매력 칸 |
| 학생 | 대학 길 / 취업 길 | 대학: 성장 칸 + 수능 / 취업: 돈 칸 |
| 중년 | 창업 길 / 회사 길 | 창업: 큰돈과 위기 섞임 / 회사: 안정 |
| 노년 | 도시 길 / 시골 길 | 도시: 돈 오르내림 / 시골: 행복 칸 |

**B. 선택만 하는 칸** (🛑 정지 칸, 길은 그대로): 동아리, 직업 선택, 취업 박람회, 입양·반려동물

- 여기에 단계마다 이벤트 길 1개 (아래). 단계마다 갈라지는 곳은 1~2개

## 이벤트 맵 (세부는 `11-event-maps.md`)
- 2026-10-15 변경: 옆길형과 별도 화면형을 합쳐 **단계마다 이벤트 길 1개** (칸마다 미니게임, 한 가지에 치중)

- **옆길형**: 본 길에서 빠져 특별 구역을 지나 다시 복귀 (횟수 안에서 이동)
- **별도 화면형**: 입구 칸에 멈추면 다른 화면에서 미니게임·특별 이벤트 후 제자리
- 아이디어는 미정 (사용자가 생각나면). 예시로 냈던 것: 놀이공원, 수학여행, 축제, 수능, 해외여행, 오디션, 창업, 주식시장, 카지노, 세계일주

## 칸 종류
- 💰 돈 (보너스) / 📈 성장 (능력치) / 😊 행복 / ⚠️ 위기 / 🎴 이벤트 / 🛑 정지 (필수 이벤트, 갈림길 앞, 취업 박람회 등) / 🚪 이벤트 맵 입구 / 💕 데이트
- 상점은 칸이 아니라 지나가는 지점 (`03-money.md`)
- 단계별 비중: 어린이 성장·행복 / 학생 성장·이벤트 / 청년 돈·이벤트 / 중년 돈·위기·행복 / 노년 이벤트(역전)·행복
- 구체 비율은 밸런스 단계에서

## 승리 조건
- **최종 점수 = 자산 점수 + 행복 점수**, 가장 높은 사람이 승리
- 결혼·반려동물·여행 등이 돈을 깎는 대신 행복을 올려 '돈만 쫓기' 말고 다른 전략이 생김
- 자산→점수 환산 비율, 행복 범위는 밸런스 단계에서
