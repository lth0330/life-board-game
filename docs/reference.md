# 참고 게임 조사

## 「인생게임 for Nintendo Switch」 (타카라토미, 2023-10-06) — 주 참고
사용자가 직접 플레이한 게임. 한 판 2시간 넘음.
- 인생 7단계: 아기, 초등, 중학, 고교, 청년, 장년, 노년
- 능력치: 지력, 체력, 센스, 운 (운은 룰렛, 나머지는 선택지·동아리 활동으로 성장)
- 직업: 능력치가 조건을 넘으면 취업. 회사원은 자동 승진, 야구선수·아이돌은 룰렛으로 승진
- 연애(데이트), 보물 모으기, 억만장자 목표
- 같은 칸에 멈추면 미니게임, 후반 역전 요소, CPU 성향(지력형, 연애형 등)
- 모드: 일생 / 어린이만 / 어른부터(어린이만 모드 데이터 이어받기 가능) / 보드게임 그대로
- 1~4인, 로컬·온라인
- **사용자 플레이 기억**: 단계마다 룰렛 횟수가 정해져 있고 마지막 단계만 골 도착 경주. 길은 길거나 원형이었던 것 같음
- 출처: https://gamebiz.jp/news/373177

## The Game of Life 2 (Marmalade Game Studio, 스위치 2021) — 보조 참고
- 해즈브로 라이선스, 모바일 게임을 콘솔로 이식
- 점수: 지식·부·행복 (돈만으로 승부하지 않음)
- 갈림길: 대학/취업, 결혼/싱글, 자녀/반려동물, 집, 이직. 결혼·학위 재도전 기회
- 핀 색·옷·탈것 꾸미기 해금, 테마 월드 DLC (동화 왕국, 유령 언덕, 공룡 등)
- 로컬 4인, 온라인, 크로스플랫폼
- 평가: OpenCritic 60, Steam 77%. 불만: **같은 직업·이벤트 반복**, 가격 대비 짧음(한 판 약 30분)
- 출처: https://store.steampowered.com/app/1455630/ , https://opencritic.com/game/11145/the-game-of-life-2

## 원작 보드게임 (해즈브로, 1960)
- 룰렛 1~10, 월급날 칸(지나가면 월급, 멈추면 보너스), 주황 정지 칸(결혼·이직·집)
- 액션 카드, 집 카드, 은퇴지 2곳(부자 동네 고위험 / 시골 안전), 최종 순자산 승부
- 출처: https://gamerules.com/rules/the-game-of-life/
