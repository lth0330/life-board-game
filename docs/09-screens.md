## 방향 결정 (2026-10-15, 사용자)
- 한 화면에 정보를 다 띄우지 않음. **기본 정보만 위에** (단계·나이, 돈, 행복, 운세, 차례 순서, 남은 룰렛)
- 나머지(다른 플레이어 상세, 주식, 카드 등)는 버튼으로 열어 봄
- 본 화면은 **실제 보드게임처럼 퀄리티 높게**: 테이블 위 기울어진 보드판, 서 있는 말, 튀어나온 건물(학교·상점·결혼식장·집), 실물 같은 룰렛
- 시안 D(실제 보드게임형)를 캔버스 맨 앞에 추가. CSS로 흉내 낸 것이라 실제 품질은 그림·3D 자원에 달림
- 미정: 2D 그림 방식 vs 3D 방식 (아래 대화)
