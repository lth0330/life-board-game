# 05. 연애와 결혼

## 연애
- **여러 사람의 호감도를 동시에** 올릴 수 있음 (한 명만 사귀는 방식 아님)
- 💕 **데이트 칸** (공짜): 후보 2~3명이 나오고 골라서 데이트 → 그 사람 호감도 상승. 이미 만난 사람이 다시 나올 수도 있음
- 호감도는 % (0~100)

### 소개팅 회사 (사용자 아이디어)
- 상점 지점에서 가입, 매 턴 회비
- 새 사람은 한 턴에 **한 명씩** 소개 → 마음에 들면 추가 비용 내고 연애 시작(호감도 목록에 추가)
- 해지는 **플레이어가 직접 할 때만** (매 턴 자유). 연애를 시작해도 자동 해지 안 됨
- 가입 중이면 **매 턴 시작마다 만남**: 새 사람 소개받기 vs 전에 만난 사람과 데이트(호감도↑) 중 선택
- 핵심 장점: **확실함** — 이동은 그대로 하면서, 데이트 칸을 못 밟아도 매 턴 누군가를 만남
- 단점: 돈이 많이 들고 한 턴에 한 명만
- 회원 등급 (2026-10-15 세부)

| | 일반 | VIP |
|---|---|---|
| 매 턴 회비 | 30만 | 100만 |
| 연애 시작 비용 | 100만 | 300만 |
| 특전 | 속성 1개 지정 → 그 속성이 높은 사람 | 속성 지정 + ★3 이상 확률 크게↑ |

- 가입: 청년·중년, 미혼 또는 이혼한 사람
- 결혼하면 자동 해지 (그 밖에는 직접 해지할 때만)

## 반려동물
- **청년, 중년 둘 다** 가능 (중년은 갈림길에서도 선택 가능)
- 얻는 방법: 상점 지점에서 구매 + "유기견을 만났다" 같은 이벤트
- 수명: 15~20턴 정도, 운세에 따라 조금씩 달라짐
- 장점: 매 턴 행복 소폭 상승, 낮은 확률로 좋은 이벤트 (예: 꾸준한 산책으로 체력 상승)
- 단점
  - 사료값 매 턴 지출
  - 나쁜 이벤트: 병원비, 가구를 할퀴거나 부숨 등
  - 사망 시 행복 하락. 단, 너무 빨리 죽지만 않으면 쌓인 행복이 더 커서 총량은 이득

## 중년 연애
- 중년 길에서 **결혼식장 앞까지만 데이트 칸**이 있음. 결혼식장을 지나면 데이트 칸 없음 (결혼 기회가 없으므로)
- 중년 결혼식장을 지나면 소개팅 회사도 자동 해지 (회비만 나가지 않게)

## 결혼 지점
- **청년 2곳(깊이 10, 20), 중년 1곳(깊이 13)**. 상점처럼 칸이 아니라 **지나가면 자동 이벤트**
- 이벤트: **고백** 또는 **비혼** 선택
  - 고백: 호감도 **50% 이상**인 사람 중에서 골라 고백 → 호감도에 비례해 성공 확률
  - 실패하거나 비혼을 고르면 다음 결혼 지점까지 솔로
- 이미 결혼한 사람은 이벤트 없이 지나감
- 청년에 결혼: 이후 **출산 가능**
- 중년에 결혼: **출산 불가, 입양 가능**

### 자녀와 입양
- 출산: **청년에 결혼한 사람만, 청년 단계 안에서** (중년은 40세 이상이라 출산 불가 — 현실 반영)
  - 청년에 **결혼하자마자 한 번** "아이를 가질까요?"를 물음 (2026-10-15 추가)
  - 그 뒤에도 💕 **데이트 칸**에 들어가면 낳을지 말지 **직접 선택**
  - 자녀 **최대 3명**
- 입양: **중년 단계에서 1번만** 선택 가능. 대상: 중년 결혼 지점에서 결혼한 사람 / 청년에 결혼했지만 자녀가 없는 사람
- 입양한 자녀도 좋은 자녀 이벤트는 있지만, 친자녀보다 조금 약하거나 횟수가 적음

### 자녀 키우기와 아이테크 (2026-10-15 확정)
자녀가 이득만 주던 문제(매 턴 행복 +1, 양육비 20만이라 많이 낳을수록 무조건 이득)를 사용자가 지적 → 키우는 비용과 커서 돌려받는 것으로 바꿈. 숫자는 초안.

| | 친자녀 | 입양 자녀 |
|---|---|---|
| 지원금 | 출산 +100만 | 입양 +50만 |
| 나이 | 0살로 태어남 | **5~8살**에 입양 → 그만큼 빨리 어른이 돼서 양육비가 덜 듦 |
| 교육 투자 | **중년 첫 차례**에 고름 | 입양할 때 고름 |
| 성장 판정 | 내 능력치 평균 + 교육 + 주사위 | 같음 **-1** (같은 교육이어도 크게 성공 확률이 낮음) |
| 용돈 (매 턴) 크게 성공 / 보통 / 잘 안 풀림 | **100만 / 60만 / 20만** | **80만 / 60만 / 10만** |

- 양육비 (1명당 매 턴, 어른이 될 때까지): 청년 20만 / 중년부터는 교육 투자에 따라 안 함 20만 · 보통 40만 · 많이 80만
- 교육 판정 보너스: 안 함 0 / 보통 +2 / 많이 +4
- 태어나고(입양 아이는 0살 기준으로) **20년 뒤 어른**이 되면 판정. **운세는 넣지 않음** (매 턴 바뀌므로, 사용자 결정)
- 판정 점수 14 이상 크게 성공(행복 +5), 10 이상 보통(행복 +2), 그 밑은 잘 안 풀림(행복 -2)
- 잘 안 풀린 자녀: 용돈은 조금 주지만 **아주 가끔 나쁜 사건** (사고 뒷수습 등)
- **좋은 사건** (사용자 요청): 7살 이상 어린 자녀 1명당 매 턴 확률 안 함(교육 고르기 전 포함) 2% · 보통 4% · 많이 6%. 공부를 잘해 상을 받아 옴(행복 +3) / 대회 상금·장학금(돈 + 행복 +1)
- **육순(60)·칠순(70) 잔치**: 어른이 된 자녀 1명당 용돈 잘 안 풀림 50만 · 보통 150만 · 크게 성공 300만, 행복 +3
- 노년 '손주가 찾아왔다' 카드는 아이가 있을 때만 (없으면 '옛 친구가 놀러 왔다' +3). 전에는 아이가 없어도 나오던 버그
- **교육을 적게 하면 말썽** (사용자 결정): 교육을 고른 뒤 어린 자녀 1명당 매 턴 나쁜 사건 확률 안 함 8% · 보통 3% · 많이 2%. 안 함/보통은 학교 사고(돈·행복 -3)·방황(행복 -2), 많이는 공부 스트레스(행복 -2)
- 매 턴 행복 +1은 **어릴 때만** (자녀마다). 어른이 되면 행복 대신 용돈 (2026-10-15 밸런스: 어른이 돼도 +1이면 결혼한 사람끼리 자녀 있음 207점 · 없음 149점으로 너무 유리)
- 교육 시험 (600판, 모든 AI가 결혼하면 아이를 가짐): 판정 결과 [잘 안 풀림/보통/크게 성공] 안 함 174/107/2 · 보통 89/161/33 · 많이 17/172/94 → 결과 차이는 확실. 그런데 **자녀 있던 판 총점은 보통 195 · 안 함 191 · 많이 187**로 거의 같음 (자녀가 대개 중년 후반에 어른이 돼서 용돈 받는 기간이 짧음, 아이도 평균 1.2명)
- AI 80판 시험: 친자녀 잘 안 풀림 18% · 보통 56% · 크게 성공 26% / 입양 크게 성공 20% (AI는 대부분 교육 '많이'를 고름)

### 나중에 넣을 것 (사용자 예정)
- ~~자녀가 결혼하면 다른 플레이어들이 축의금, 손주를 낳으면 축의금~~ → 2026-10-29에 넣음 (맨 아래)
- 중년 '새 가족' 칸은 **입양 / 반려동물 / 안 함** (A안 확정). 중년 결혼 지점 **뒤**에 둠 → 중년에 결혼한 사람도 입양 가능

### 결혼식장 (3단계)
- 높은 단계일수록 비쌈
- 대신 다른 플레이어에게 **축의금**을 많이 받을 확률 상승 + 좋은 이벤트 발생
- 축의금은 플레이어끼리 주고받는 요소 → 주제 8에서 세부

## 배우자
- 속성 4개: **외모 / 재력 / 명성 / 성격**
  - 배우자마다 분포가 다름: 외모만 높고 나머지 평범 / 전부 평타 이상 / 명성·재력 높은데 성격·외모 나쁨 등
- 등급 **5단계**: **별 ★ ~ ★★★★★** (2026-10-15 확정)
  - 등급이 높을수록 같은 분포라도 수치가 높음
  - 높을수록 결혼하기 어려움 (내 직업·재력으로 보정. 고소득·인정받는 직업, 고급차면 유리)
- **직업 분야 태그** 하나 (주식 종목 분야와 맞춤, 예: 배우·엔터 / 의사·의료 / 개발자·IT)
  - 배우자 승진·전직은 없음
  - 배우자 스캔들 → 그 분야 주가 하락, 배우자 큰 성과 → 상승
  - 속성과 어울리게 (명성 높으면 엔터, 재력 높으면 의료·사업 등)

### 숨은 특성 (사용자 아이디어)
- 배우자마다 좋거나 나쁜 특성 **하나**. **결혼 전에는 모르고 결혼 뒤에 드러남**
- 특성에 따른 이벤트가 가끔 발생
- 예시(사용자): 도박증, 명품만 사는 사람, 대운(나한테 좋은 영향), 까칠함 등
- 속성과 **약한 연관**: 등급은 좋은/나쁜 비율에 영향 없음. 속성이 높거나 낮으면 연관 특성이 **나올 확률만** 오름 (확정 아님). 나머지는 랜덤
- **성격이 높으면** 성격 낮을 때 잘 나오는 특성(까칠함, 게으름)이 나올 확률이 오히려 **내려감**

| 특성 | 효과 / 가끔 이벤트 | 잘 나오는 배우자 |
|---|---|---|
| 🍀 대운 | 내 운세가 좋게 나올 확률↑ | 연관 없음 (순수 랜덤) |
| 🪙 짠돌이 (좋고 나쁨 섞임) | 매 턴 지출↓, 가끔 돈을 모아 옴 / 대신 행복↓ | 재력 낮음 |
| 🍳 요리왕 | 가족 행복↑, 가끔 집들이 대성공 | 성격 높음 |
| 🧠 재테크 고수 | 가끔 주식 수익 | 재력 높음 |
| 👨‍👧 육아 천재 | 자녀 이벤트 효과↑ | 성격 높음 |
| 💪 운동 마니아 | 가끔 같이 운동 → 내 체력↑ | 외모 높음 |
| 🤝 인맥왕 | 가끔 좋은 기회 소개 (전직 기회, 주식 정보, 큰 거래) | 명성 높음 |
| 🎰 도박증 | 가끔 복권·도박으로 돈 손실 | 명성 높음 |
| 👜 명품 중독 | 매 턴 지출↑, 가끔 큰 쇼핑 | 외모 높음 |
| 😤 까칠함 | 가끔 부부 싸움 → 행복↓ | 성격 낮음 (성격 높으면 확률↓) |
| 🛋️ 게으름 | 행복↓ | 성격 낮음 (성격 높으면 확률↓) |
| 🍺 술고래 | 가끔 사고·병원비 | 명성 높음 (모임·회식) |
| 👀 바람기 | 외도 사건 확률↑ | 외모·명성 높음 |

- 검토 후 넣지 않은 안: 잔소리꾼(성격 높음, 나쁨), 승부사(성격 낮음, 좋음)

### 속성별 효과

| 속성 | 높을 때 | 낮을 때 |
|---|---|---|
| 💄 외모 | 결혼할 때 **1회** 큰 행복 보너스, 자녀 매력 보너스 | 결혼할 때 행복 하락 |
| 💰 재력 | 결혼 지참금, 맞벌이 수입 많음, 가끔 **지원 이벤트** | 맞벌이 수입 적음 (0은 아님) |
| ⭐ 명성 | **하이 리스크 하이 리턴**: 방송·광고 출연(다른 속성 보너스보다 한 번에 크게), 결혼식 화제성(축의금 크게↑ + 1회 행복), 배우자 성과 → 분야 주가↑(미리 사 두면 대박), 인맥으로 조건 1 완화 / 대신 **스캔들**(행복↓, 분야 주가↓) | 특별한 효과 없음 |
| 💗 성격 | **매 턴** 행복 소폭 상승, 이혼 확률 낮춤 | 이혼 확률 상승, 행복 감소 이벤트 |

- 명성을 승진·대출 한도와 잇는 안은 버림 (어색하고 재력과 겹침)
- 명성 높음은 나쁜 특성(도박증·술고래·바람기)이 많아서 좋은 쪽을 키움 (A안). 술고래를 성격 쪽으로 옮기는 안(B)은 안 함
- 속성별 성향: 재력 = 비교적 안전 / 성격 = 무난 / 외모 = 결혼 때 1회 / 명성 = 인생 역전 아니면 사고

## 이혼
- 나쁜 이벤트로만 발생. 운세 적용 (대길이면 "위기를 넘기고 화해")
- **청년 단계에는 이혼 없음.** 이혼은 중년부터
- 결과
  - 💔 행복 크게 하락
  - ❌ 배우자 효과 사라짐
  - 🏠 재산 분할: 재력 비교 — 배우자가 더 부자면 오히려 내가 받음
  - 💸 **위자료: 잘못한 쪽이 냄**. 배우자 잘못이면 내가 받음
  - 위자료는 이혼으로 잃는 것(행복, 맞벌이 수입 등)보다 **항상 적게** → 이혼당해서 이득 보는 일 없게
- 누구 잘못인지는 **사건**으로 정함
  - 내 잘못: 도박중독, 오래 간 마이너스 자산 (플레이어는 명성 수치가 없어서 '내 스캔들'은 뺌)
  - 배우자 잘못: 💔 외도 / 💸 몰래 진 빚(일부 떠안을 수도) / 🚨 범죄·큰 스캔들(명성 높을수록 잘 일어남)
  - **배우자 성격은 '잘못'이 아니라 배우자 잘못 사건이 일어날 확률**을 올림 (성격 낮음 = 확실한 단점)
  - 양육비 없음 (뺌)
- 재결합 시 전 배우자 호감도: 내 잘못으로 이혼했으면 크게 하락, 배우자 잘못이었으면 조금만 하락
- 재혼: 중년에 이혼했고 **중년 결혼 지점을 아직 안 지났으면** 그 지점에서 **전 배우자와 재결합** 또는 **새 사람과 결혼** 가능. 지난 뒤 이혼하면 재혼 없음
