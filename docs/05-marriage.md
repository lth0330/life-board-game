# 05. 연애와 결혼

## 연애
- **여러 사람의 호감도를 동시에** 올릴 수 있음 (한 명만 사귀는 방식 아님)
- 💕 **데이트 칸** (공짜): 후보 2~3명이 나오고 골라서 데이트 → 그 사람 호감도 상승. 이미 만난 사람이 다시 나올 수도 있음
- 호감도는 % (0~100)

### 소개팅 회사 (사용자 아이디어)
- 상점 지점에서 가입, 매 턴 회비
- 매 턴 **한 명씩** 소개 → 마음에 들면 추가 비용 내고 연애 시작, 아니면 다음 턴에 새 사람
- 소개팅으로 연애를 시작하면 **회원권 자동 해지**. 직접 해지도 매 턴 자유
- 핵심 장점: **확실함** — 이동은 그대로 하면서, 데이트 칸을 못 밟아도 매 턴 누군가를 만남
- 단점: 돈이 많이 들고 한 턴에 한 명만
- 회원 등급
  - 일반: 원하는 속성 지정 가능 ("성격 좋은 사람으로")
  - VIP: 회비 비쌈, 높은 등급이 나올 확률 상승

## 결혼 지점
- **청년 2곳, 중년 1곳**. 상점처럼 칸이 아니라 **지나가면 자동 이벤트**
- 이벤트: **고백** 또는 **비혼** 선택
  - 고백: 호감도 **50% 이상**인 사람 중에서 골라 고백 → 호감도에 비례해 성공 확률
  - 실패하거나 비혼을 고르면 다음 결혼 지점까지 솔로
- 이미 결혼한 사람은 이벤트 없이 지나감
- 청년에 결혼: 이후 **자녀 가능**
- 중년에 결혼: 결혼은 되지만 **자녀 불가**

### 결혼식장 (3단계)
- 높은 단계일수록 비쌈
- 대신 다른 플레이어에게 **축의금**을 많이 받을 확률 상승 + 좋은 이벤트 발생
- 축의금은 플레이어끼리 주고받는 요소 → 주제 8에서 세부

## 배우자
- 속성 4개: **외모 / 재력 / 명성 / 성격**
  - 배우자마다 분포가 다름: 외모만 높고 나머지 평범 / 전부 평타 이상 / 명성·재력 높은데 성격·외모 나쁨 등
- 등급 **5단계** (이름은 나중에)
  - 등급이 높을수록 같은 분포라도 수치가 높음
  - 높을수록 결혼하기 어려움 (내 직업·재력으로 보정. 고소득·인정받는 직업, 고급차면 유리)
- **직업 분야 태그** 하나 (주식 종목 분야와 맞춤, 예: 배우·엔터 / 의사·의료 / 개발자·IT)
  - 배우자 승진·전직은 없음
  - 배우자 스캔들 → 그 분야 주가 하락, 배우자 큰 성과 → 상승
  - 속성과 어울리게 (명성 높으면 엔터, 재력 높으면 의료·사업 등)

### 속성별 효과

| 속성 | 높을 때 | 낮을 때 |
|---|---|---|
| 💄 외모 | 결혼할 때 **1회** 큰 행복 보너스, 자녀 매력 보너스 | 결혼할 때 행복 하락 |
| 💰 재력 | 결혼 지참금, 맞벌이 수입 많음, 가끔 **지원 이벤트** | 맞벌이 수입 적음 (0은 아님) |
| ⭐ 명성 | **양날의 검**: 방송·광고 출연 이벤트(돈·행복), 인맥으로 전직·조건 갈림길 능력치 조건 1 완화 / 대신 **스캔들** 이벤트(행복↓, 분야 주가↓) | 특별한 효과 없음 |
| 💗 성격 | **매 턴** 행복 소폭 상승, 이혼 확률 낮춤 | 이혼 확률 상승, 행복 감소 이벤트 |

- 명성을 승진·대출 한도와 잇는 안은 버림 (어색하고 재력과 겹침)

## 이혼
- 나쁜 이벤트로만 발생. 성격 나쁜 배우자일수록 확률 높음. 운세 적용 (대길이면 "위기를 넘기고 화해")
- 결과
  - 💔 행복 크게 하락
  - ❌ 배우자 효과 사라짐
  - 🏠 재산 분할: 재력 비교 — 배우자가 더 부자면 오히려 내가 받음
  - 💸 **위자료: 잘못한 쪽이 냄**. 배우자 잘못이면 내가 받음
  - 양육비 없음 (뺌)
- 재혼: 확인 중 (아래)

## 미정
- 이혼 사유와 '누구 잘못'을 어떻게 정할지

- 등급 5단계 이름
