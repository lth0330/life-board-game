# 사건 장면 (캐릭터가 직접 나오는 짧은 애니메이션) — 2026-11-27 계획

## 왜
사용자: 사건이 나오면 그림 한 장 + 글 대신, **그 플레이어의 캐릭터가 직접 겪는 장면**(먹기, 길 가다 넘어지기, 교통사고 등)을 짧게 보여 주고 싶음.

## 정한 것 (11-27 사용자)
- **AI 영상이 아니라 코드 애니메이션(A안)**. 이유: 캐릭터를 플레이어가 꾸미고 나이에 따라 바뀌어서, 미리 만든 영상엔 '내 캐릭터'가 못 나옴. 그때그때 AI로 만들면 유료 + 몇 분씩 걸림
  - 알아본 것: 영상 API는 사실상 무료 없음. Kling은 무료 크레딧 10(1개 30), Dreamina는 1개 60·하루 120쯤(워터마크 있음). 결혼 케이크 영상 1개 시험 → 물건 그림 영상은 의미 없다고 사용자 판단
- 시안('넘어지기', 앞모습 그대로 통째로 기울이기)을 보고: **이 느낌으로, 작업이 커도 퀄리티를 더 살려서** 여러 장면
- **길이: 사건에 따라 8~15초** (작은 사건 8초쯤, 큰 사건 15초까지)
- **띄울 곳: 사건 창 윗부분** (장면 아래에 사건 이름·돈·행복 변화 글)
- **모든 플레이어 사건에 장면** (AI·친구 포함)
  - 사람 차례 장면은 그 사람이 보는 동안 다른 사람도 같이 보는 것이라 **기다림이 늘지 않음**(사용자 지적). 늘어나는 건 **AI 차례**뿐(지금 AI 사건 창 1.5초) → 따로 '장면 보기' 설정은 안 만들고, 기존 **게임 빠르기**에 맞춰 AI 장면 속도만 바꿈(보통 = 끝까지, 빠르게 = 2배속). 누르면 바로 넘기기

## 구조
- 장면은 **사건 문장**으로 고름 (예: `/넘어져/` → 넘어지기). 게임 규칙(`engine`)은 안 건드림. 온라인도 각 기기가 같은 문장으로 같은 장면 → 서버 그대로
- 맞는 장면이 없으면 지금처럼 그림(`event-*.webp`)
- 판 위 캐릭터(`art/Character.tsx`, 앞모습)는 그대로. 장면에서만 새 **옆모습 + 관절 캐릭터**

## 단계
1. **기반**
   - 옆모습 캐릭터: 지금 옷·머리·피부·나이 모습(아기·어린이·학생·어른·노인 지팡이)을 옆에서. 팔(위팔·아래팔)·다리(허벅지·종아리) 관절, 표정은 지금 8가지를 옆얼굴로
   - 장면 틀: "몇 초에 어떤 자세" 목록 → 부드럽게 이어 움직임. 공통 효과(쿵·먼지·별·땀·하트·김·말풍선·화면 흔들림), 소품(돌·자동차·식탁·그릇·침대…), 배경(먼저 코드 그림, 나중에 ChatGPT 그림 가능)
   - 게임 연결: 사건 창 위에 장면, 누르면 넘김, 내 사건 창 자동 닫힘(5초)을 장면 길이에 맞춤, '움직임 줄이기'면 멈춘 그림
2. **시험 장면 3개** → 미리보기 페이지로 확인 → 기반 다듬기
   - 넘어지기(다시), 먹기(친구들과 떡볶이·맛집, 여러 명), 교통사고(접촉 사고, 귀엽게 '쿵'·범퍼 찌그러짐, 다치는 모습 없음)
3. **장면 늘리기** (자주 나오는 사건부터, 4~5개씩 확인받고 넣기)
   - 몸: 감기, 허리·무릎 삐끗, 병원, 스쿠터 넘어짐
   - 사고·집: 접촉 사고, 집에 물 샘, 태풍, 보이스피싱·사기
   - 놀기: 노래방, 등산, 놀이동산, 밤샘 게임, 반려동물 산책, 텃밭
   - 큰 사건: 결혼, 아기 탄생, 내 집 마련, 취업·승진, 졸업, 복권 당첨 (지금 배너 위 작은 장면 `SCENES`를 바꿈)
   - 연애: 데이트
4. (원하면) ChatGPT 배경 그림, 효과음

## 시안
- 11-27 '넘어지기' 첫 시안: 앞모습 캐릭터를 통째로 기울임, 5.5초(걷기 → 걸림 → 꽈당·쿵·먼지 → 별 → "괜찮아…!" → 걸어 나감), 캐릭터 3명(기본·원피스·71세 지팡이). 부족한 점: 옆으로 걸어도 정면, 판자처럼 넘어짐 → 1단계 옆모습·관절로 해결
