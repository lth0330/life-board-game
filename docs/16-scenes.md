# 사건 장면 (캐릭터가 직접 나오는 짧은 애니메이션) — 2026-11-27 계획

## 왜
사용자: 사건이 나오면 그림 한 장 + 글 대신, **그 플레이어의 캐릭터가 직접 겪는 장면**(먹기, 길 가다 넘어지기, 교통사고 등)을 짧게 보여 주고 싶음.

## 정한 것 (11-27 사용자)
- **AI 영상이 아니라 코드 애니메이션(A안)**. 이유: 캐릭터를 플레이어가 꾸미고 나이에 따라 바뀌어서, 미리 만든 영상엔 '내 캐릭터'가 못 나옴. 그때그때 AI로 만들면 유료 + 몇 분씩 걸림
  - 알아본 것: 영상 API는 사실상 무료 없음. Kling은 무료 크레딧 10(1개 30), Dreamina는 1개 60·하루 120쯤(워터마크 있음). 결혼 케이크 영상 1개 시험 → 물건 그림 영상은 의미 없다고 사용자 판단
- 시안('넘어지기', 앞모습 그대로 통째로 기울이기)을 보고: **이 느낌으로, 작업이 커도 퀄리티를 더 살려서** 여러 장면
- **길이: 사건에 따라 8~15초** (작은 사건 8초쯤, 큰 사건 15초까지)
- **띄울 곳: 사건 창 윗부분** (장면 아래에 사건 이름·돈·행복 변화 글)
- **모든 플레이어 사건에 장면** (AI·친구 포함)
  - 사람 차례 장면은 그 사람이 보는 동안 다른 사람도 같이 보는 것이라 **기다림이 늘지 않음**(사용자 지적). 늘어나는 건 **AI 차례**뿐(지금 AI 사건 창 1.5초) → 따로 '장면 보기' 설정은 안 만들고, 기존 **게임 빠르기**에 맞춰 AI 장면 속도만 바꿈(보통 = 끝까지, 빠르게 = 2배속). 누르면 바로 넘기기

## 구조
- 장면은 **사건 문장**으로 고름 (예: `/넘어져/` → 넘어지기). 게임 규칙(`engine`)은 안 건드림. 온라인도 각 기기가 같은 문장으로 같은 장면 → 서버 그대로
- 맞는 장면이 없으면 지금처럼 그림(`event-*.webp`)
- 판 위 캐릭터(`art/Character.tsx`, 앞모습)는 그대로. 장면에서만 새 **옆모습 + 관절 캐릭터**

## 단계
1. **기반**
   - 옆모습 캐릭터: 지금 옷·머리·피부·나이 모습(아기·어린이·학생·어른·노인 지팡이)을 옆에서. 팔(위팔·아래팔)·다리(허벅지·종아리) 관절, 표정은 지금 8가지를 옆얼굴로
   - 장면 틀: "몇 초에 어떤 자세" 목록 → 부드럽게 이어 움직임. 공통 효과(쿵·먼지·별·땀·하트·김·말풍선·화면 흔들림), 소품(돌·자동차·식탁·그릇·침대…), 배경(먼저 코드 그림, 나중에 ChatGPT 그림 가능)
   - 게임 연결: 사건 창 위에 장면, 누르면 넘김, 내 사건 창 자동 닫힘(5초)을 장면 길이에 맞춤, '움직임 줄이기'면 멈춘 그림
2. **시험 장면 3개** → 미리보기 페이지로 확인 → 기반 다듬기
   - 넘어지기(다시), 먹기(친구들과 떡볶이·맛집, 여러 명), 교통사고(접촉 사고, 귀엽게 '쿵'·범퍼 찌그러짐, 다치는 모습 없음)
3. **장면 늘리기** (자주 나오는 사건부터, 4~5개씩 확인받고 넣기)
   - 몸: 감기, 허리·무릎 삐끗, 병원, 스쿠터 넘어짐
   - 사고·집: 접촉 사고, 집에 물 샘, 태풍, 보이스피싱·사기
   - 놀기: 노래방, 등산, 놀이동산, 밤샘 게임, 반려동물 산책, 텃밭
   - 큰 사건: 결혼, 아기 탄생, 내 집 마련, 취업·승진, 졸업, 복권 당첨 (지금 배너 위 작은 장면 `SCENES`를 바꿈)
   - 연애: 데이트
4. (원하면) ChatGPT 배경 그림, 효과음

## 시안
- 11-27 '넘어지기' 첫 시안: 앞모습 캐릭터를 통째로 기울임, 5.5초(걷기 → 걸림 → 꽈당·쿵·먼지 → 별 → "괜찮아…!" → 걸어 나감), 캐릭터 3명(기본·원피스·71세 지팡이). 부족한 점: 옆으로 걸어도 정면, 판자처럼 넘어짐 → 1단계 옆모습·관절로 해결

## 장면 만들기 기준 (11-27~28 사용자 피드백 모음) — 새 장면 만들 때 먼저 읽기
**이야기**
- 사건이 **일어날 수 없는 나이·상황은 만들지 않기** (유치원생 결혼·병원·출산, 노인 결혼 등). 게임 코드에서 사건이 나오는 나이를 확인해 `ages`에 적기. 아이 감기처럼 나이에 따라 장면을 따로 만들기
- **안 좋은 일은 아파하며 끝내되 일반화하지 않기**: "괜찮아" 대신 "아야야" (넘어지기는 절뚝절뚝 길게). 하지만 모든 안 좋은 일을 울며 걸어가는 끝으로 만들지 않기 (허리는 "아이고 내 허리"로 잠깐 있다 끝)
- **급전개 금지, 중간 단계를 빼먹지 않기**: 싸움은 원인(지각)부터 천천히 커지게, 보이스피싱은 전화 → 은행 사칭 → 걱정 → 송금 요구 → 망설임 → 송금 → 끊김 → 다시 걸기 → 없는 번호. 물건을 주고받는 순간(아기·열쇠·부케·반지·선물)도 보여 주기
- **왜 그 장면인지 바로 알게**: 내 집 마련 = 계약 도장 → 열쇠 → 큰 새집·'축 입주' → 들어감. 아기 탄생 = 엄마가 아기를 안고 누워 있고 남편이 옴 (어디선가 아기를 데려오면 이상함)
- **사건과 맞는 말·물건**: 복권은 "1등이다!", 승진 선물은 명패(취업 사원증·합격 합격증), 데이트 선물은 남녀 누구나 어울리는 것(목도리를 받아 목에 두름 — 목걸이를 손에 쥐는 건 이상함)
- 말풍선은 읽을 만큼 오래 (끝부분일수록 서두르지 않기)

**그림·동작**
- **물건은 진짜처럼**: 차 앞뒤(보닛·앞유리·트렁크·전조등·후미등), 의자는 의자처럼(등받이·다리, 엉덩이 위치에 맞게, 크기 적당히), 떡볶이(작은 접시 각자 하나, 빨간 떡·어묵), 병원 침대(등받이·난간·링거), 우산(살·손잡이), 물뿌리개, 상추·바구니, 벽돌, 학사모(머리에 딱 맞게 크게), 탬버린(크고 방울)
- **크기 비율**: 집 문이 사람보다 커야 함(집 장면은 사람을 작게 `HOUSE_SIZE`), 그릇·소품이 너무 크지 않게
- **방향·시선**: 마주 보는 상대가 없으면 정면(`FrontActor`)으로 — 식탁 건너편 사람, 사진 찍히는 졸업생(사진사는 뒷모습). 운전하는 사람은 창문으로 보이게
- **손이 닿게**: 스쿠터 손잡이, 키보드·마우스, 체온계(엄마가 들고 잼), 젓가락. 물건이 공중에 뜨거나 순간이동하지 않게
- **치마·원피스는 앉으면 허벅지를 덮고 무릎 아래로 늘어지게** (`SideCharacter` 자동)
- **움직임은 디테일하게**: 젓가락은 집기 → 후후 → 냠 → 오물오물, 걷기·뛰기는 키프레임 많이, 화면(모니터)은 이야기대로 바뀌게(보스전 → WIN → 다음 판 → 게임 오버 → 다시)
- **배경은 처음부터 자세히**: 나무는 줄기·가지·겹친 잎 덩어리(막대사탕 금지), 창문은 창틀·커튼·창밖 풍경, 액자는 그림 내용, 빈 곳은 바위·나무·소품으로 채우기(등산 정상), 창밖은 장소에 맞게(사무실 = 도시 빌딩). 다른 소품도 너무 단순하게 하지 않기
- **(11-28 3차) 모든 소품·배경을 사각형·원·타원으로 대충 두지 않기**: 미끄럼틀, 꽃다발(포장지·리본·꽃 여러 종류), 풍선(끈이 손이나 물건에 묶임), 먹구름(겹친 덩어리·명암·빗줄기), 의자·테이블·시계·사진·현수막·창문·풀까지 하나씩 진짜 물건처럼. 필요하면 인터넷에서 실제 모양을 확인(사용자가 스크린샷을 줄 수도 있음)
- **원인과 결과가 보이게**: 창문이 깨지려면 무언가 날아와 부딪혀야 하고, 지붕 벽돌이 날아가면 지붕에 구멍이 남아야 함
- **전화기는 귀에 댔을 때 통화하는 걸로 보일 만큼 크게** (얼굴 높이의 반쯤)
- 물건을 끌 땐 손이 손잡이에 닿게 (스쿠터를 허공을 잡고 끌면 안 됨). 앉은 사람은 의자 높이·엉덩이·다리가 다 보이게(식탁에 가리지 않게), 젓가락이 식탁을 뚫지 않게
- 축하 글자('축 입주')는 문 위보다 현수막·풍선 등 따로 축하하는 물건에
- **(11-28 4차) 겹치는 순서**: 주인공 물건(미끄럼판 등)이 앞, 받침대·기둥은 뒤. **위치 맞추기**: 물이 떨어지는 자리 바로 아래에 그릇, 전화는 귀(목 아님). **가구는 한눈에 무엇인지**(소파면 등받이·팔걸이·방석). 회전하는 것은 방향까지 자연스럽게(회전목마 시계방향). 아기는 안긴 모습이 잘 보이게 크게. **시간 흐름도 이야기로**(데이트: 낮에 걷다 → 어두워짐 → 가로등 아래서 선물)
- **(11-28 5차) 말풍선 꼬리는 말하는 사람 머리 바로 위**(`Bubble`의 `at`=그 사람 x, 오른쪽 사람은 `tail="right"`). **노인 지팡이**: 손이 전화·물건으로 바쁘면 허공에 세우지 말고 가구(소파 등받이 등)에 기대어 두거나 처음부터 빼기. 겹치기 순서를 바꿀 땐 옮김(`translate`) 묶음 안에 그대로 두기
- 지팡이: 손잡이는 "?" 모양, 쪼그려도 안 사라짐, 먹거나 울 때·손이 바쁠 때는 옆에 세워 둠

## 장면 점검 방법 (11-28 사용자: "점검 똑바로 한 거 맞아?")
- 예전 방식(작은 사진 + 장면 의도를 아는 AI + 겹침·잘림만 봄)은 실패. 떡볶이·차 앞뒤·의자·집 크기 같은 걸 놓침
- **설명 없이 처음 보는 눈으로**: 장면마다 0.5~1.5초 간격 8장을 2.5배로 크게 찍어서 AI 여러 명(장면 몇 개씩 나눠)에게 장면 의도를 알려 주지 않고 보여 줌 → "무슨 사건 같아? 이야기는? 어색한 물건·크기·방향·손·빠진 단계·말풍선 가림은?" + 명확도 1~5
- 사건 이름을 못 맞히거나 물건이 진짜처럼 안 보이면 다시 고침. 고친 뒤 다시 찍어서 Claude가 직접 확인
- 나이별로 다 보기(`?cap=장면&ts=…&one=사람번호`), 마지막에 모든 장면 한 장씩 찍어 깨진 것 없는지
- 도구: 빌드 `node _b.mjs <scratchpad>/side`(vite, preview.html만), Edge headless `--force-device-scale-factor=2.5`로 캡처 → PIL로 잘라 붙임
