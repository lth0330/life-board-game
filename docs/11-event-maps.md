# 11. 이벤트 맵 (주제 12)

## 규칙 (2026-10-15)
### 옆길형
- 옆길로 빠지는 지점은 보통 **각 단계의 중간쯤**
- 옆길 길이는 **15칸 이내**
- 옆길 안에서도 **주사위·횟수는 평소와 똑같이** 진행
- 옆길이 끝나면 **원래 길로 돌아옴**
- 들어갈지는 갈림길처럼 고름
- 돌아오는 곳: 빠진 곳보다 조금 앞 (예: 15번에서 빠져 옆길 12칸 → 23번으로 합류). 옆길이 조금 느린 대신 재밌는 칸이 많음

### 별도 화면형
- 입구 칸에 **딱 멈춰야** 들어갈 수 있음 (자동차 ±1로 노릴 수 있음)
- 들어갈지 말지는 **플레이어가 선택**
- 그 턴 안에 끝나고, 끝나면 같은 칸으로 돌아옴 (주사위 횟수를 더 쓰지 않음)

## 방향 변경 (2026-10-15, 사용자)
- **옆길형과 별도 화면형을 합침**: 옆길(이벤트 길)의 칸에 도착하면 그 칸의 **미니게임**이 열림
- 기본 칸들은 고르게 분배, **이벤트 길은 한 가지에 크게 치중** (특정 능력치, 운세, 돈, 연애 등)
- 예시 (사용자 아이디어): 수능 길
  - 칸마다 과목 (수학, 영어, 국어, 과학, 외국어 등) → 그 과목 문제가 나옴
  - **지력이 높을수록 쉬운 문제**, 낮을수록 어려운 문제 (예: 수학은 2차 방정식, 난이도 조절)
  - **지력이 높으면 객관식, 낮으면 주관식**
- **수능 길은 취소** (사용자): 수능은 대학 가려면 필수라 옆길에 맞지 않고, 지식 문제를 내는 방식도 안 맞음
  - 대신: 수능은 본 길의 대학 갈림길에 포함 (검토 중), 학생 이벤트 길은 다른 것으로 (검토 중)
- 원칙은 유지: 능력치는 결과가 아니라 **미니게임 난이도**를 바꿈

## 처음 초안 목록 (참고)
- 옆길형: 놀이공원(어린이) / 수학여행(학생) / 해외여행(청년) / 가족 캠핑장(중년) / 세계일주(노년)
- 별도 화면형: 운동회(어린이) / 수능(학생, 장학금) / 오디션(청년, 데뷔 기회) / 카지노(중년, 도박중독 연결) / 손주 잔치(노년)
