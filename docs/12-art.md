## 나중에 고쳐야 할 것
### 그림
- [ ] 캐릭터를 제대로 된 일러스트나 3D 모델로 (지금은 단순한 도형)
- [ ] 꾸미기 아이템 그림 다시 그리기, 개수 늘리기 (계절 옷, 직업 옷, 테마 옷 등)
- [ ] 건물을 단계·테마별로 다시 그리기. 결혼식장 같은 중요한 건물과 이벤트 칸은 특별하게 (사용자 요청, `09-screens.md`)
- [ ] 칸 아이콘 다시 그리기
- [ ] 로고 다시 디자인
- [ ] 미니게임마다 그림과 배경 (지금은 버튼·게이지·글자뿐)
- [ ] 판 안 시점을 진짜 3D로 (지금은 CSS로 기울인 평면)

### 연출
- [ ] 걷기: 지금은 칸에서 칸으로 순간이동처럼 넘어감 → 걷는 동작, 발걸음
- [ ] 주사위: 지금은 화면 가운데로 날아옴 → 실제 보드 위 물리 굴림
- [ ] 이벤트별 장면 (결혼식, 복권 당첨, 이혼, 수능 등) 전용 화면
- [ ] 효과음·배경음 (아직 없음)

### 계정·저장
- [ ] **진짜 로그인** (다른 기기에서도 이어 하기): Supabase 같은 서비스 가입이 필요해서 사용자가 계정을 만든 뒤 진행. `storage.ts`의 함수 속만 바꾸면 되게 만들어 둠
- [ ] 지금 비밀번호는 기기 안에 해시로만 저장 → 진짜 보안이 아님. 서버 로그인으로 바꿀 때 해결
- [ ] 저장 형식이 바뀌면 `SAVE_VERSION`을 올려서 예전 저장을 무시함 (지금 v8)

### 그 밖에
- [ ] 한 기기에서 여러 명이 할 때 두 번째 사람부터는 꾸미기 없이 무작위 옷
- [ ] 미니게임 화면에서 한 기기 다른 사람 차례 대결은 자동 점수
