# 06. 플레이어끼리 주고받기 (주제 8)

## 방향
- **중간 (B)**: 축하·경조사 + 같은 칸 만남 + 협력(돈 빌려주기) + **약한 방해**(가끔 생기는 방해 카드)
- 이유: 한 폰 돌려가며 하는 게임에서 방해가 강하면 분위기가 험해지고, 아예 없으면 남에게 관심이 없어짐

## 축의금
- **랜덤 (C)**: 결혼식장 단계가 높을수록 다른 플레이어가 많이 낼 확률 상승
- 배우자 명성이 높으면 크게 증가 (`05-marriage.md`)

## 돈 빌려주기 (사용자 아이디어)
- 플레이어끼리 돈을 빌려줌
- 돌려받으면: 이자 수익 + 좋은 일을 해서 **운세가 좋게 나올 확률 상승** (`04-luck.md`의 '선행')
- 빌린 사람이 파산하거나 안 갚으면: 빌려준 사람 손해
- 안 갚은 사람: **운세 확률 하락 + 신용불량 상태**, 나쁜 이벤트 발생
  - 평판은 새 수치를 만들지 않고 **신용불량 딱지**로 대신 (몇 턴 동안 은행 대출·플레이어 대출 불가, 고백 성공률↓)
- 신청: **빌리는 사람이 신청 → 빌려줄 사람이 수락**. 신청 때 금액·이자(조금/보통/많이)·기한(턴 수)을 정함. AI는 성격과 상대 신용으로 수락 판단
- **청년~노년**에만 가능 (어린이·학생 불가)
- 플레이어에게 빌리는 신청은 **게임 전체에서 상대마다 1번** (단계 상관없음) (4인이면 최대 3번). 큰 이벤트라 자주 일어나면 복잡하고 어색해짐. 그 밖에는 은행 대출 (`03-money.md` 조건)
- 은행 대출과 플레이어 대출은 **동시에 가능**
- **법적 공방** 이벤트
  - 빌린 사람이 이기면: 안 갚아도 됨. **그래도 신용불량은 붙음** (돈을 안 갚은 사실은 남음, 2026-10-15 결정)
  - 빌린 사람이 지면: 원래 돈보다 **더 많이** 갚음

## 법적 공방 (돈 빌려주기·방해 공통)
- 승패: 양쪽 주사위 + **운세 보정** + **변호사 효과** (변호사 직업이면 +2, 아니면 돈이 있을 때 자동으로 변호사를 사서 +1)
- 돈 빌려준 소송에서는 **빌린 사람이 이길 확률이 낮음**

## 방해 (약하게)
- 얻는 법·보유 제한: `07-cards.md` (방해 1장까지)

| 카드 | 효과 |
|---|---|
| ⚖️ 소송 걸기 | 법적 공방. 이기면 상대 돈 일부를 가져오고, 지면 내가 소송비 |
| 🗣️ 소문 퍼뜨리기 | 상대 행복↓ |
| 📉 주가 루머 | 한 종목 주가↓ (그 주식 많이 가진 사람이 타격) |
| 💔 연애 방해 | 상대가 좋아하는 사람의 호감도↓ |

- 막는 법: 방해는 상대에게 나쁜 일이라 **상대 운세가 적용** (대길이면 막힘)
- **역풍**: 내 운세와 상대 운세를 비교해서, 상대 운세가 나보다 좋을수록 **방해가 나에게 되돌아올 확률**이 올라감

## 같은 칸 만남 (2026-10-15 세부)
- 이동을 마친 칸에 다른 사람이 있으면 발생. **여러 명이 있으면 전부 참여**
- 이벤트 종류는 콘텐츠 단계에서 더 늘림

### 어린이·학생·노년: 만남 이벤트 (각자 자기 운세대로 좋거나 나쁨)
| 단계 | 좋을 때 | 나쁠 때 |
|---|---|---|
| 어린이 | 같이 놀았다 (행복↑) | 장난감 때문에 싸웠다 (행복↓) |
| 학생 | 같이 공부했다 (지력↑) | 숙제 베끼다 걸렸다 (**지력↓**) |
| 노년 | 옛날이야기로 웃었다 (행복↑) | 옛날 빚 이야기가 나왔다 (돈↓) |

### 청년·중년: 미니게임 대결
- **진 사람은 게임에 따라 다른 것이 떨어짐** (연타 대결은 뺌)

| 게임 | 방식 | 진 사람 |
|---|---|---|
| 주사위 대결 | 큰 수가 이김 | **운**↓ (다음 운세 한 단계↓) |
| 가위바위보 | 한 판 승부 | **능력치**↓ (랜덤 1개 -1) |
| 타이밍 멈추기 | 바늘을 가운데에 멈추기 (체력↑ → 판정 넓음) | **돈**↓ (단계 크기만큼) |

- 여러 명이면 **꼴찌만 잃음** (꼴찌가 여럿이면 모두 잃음)
- **1등은 잃은 만큼 오름**
  - 운: 1단계만 상승 (꼴찌가 여럿이어도 1단계)
  - 능력치: 꼴찌가 여럿이어도 오르는 건 1개 +1
  - 돈: 꼴찌들이 잃은 돈 **전부**
