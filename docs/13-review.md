## 1. 실제로 고친 것

### 판 배치 (중요한 곳에 못 닿던 문제)
AI 320명을 돌려 보니 단계 길의 60~70%까지만 가는 경우가 많았다. 그래서 길 뒤쪽에 있던 중요한 곳에 못 닿았다.

| 문제 | 전 | 후 |
|---|---|---|
| 학생 대학/취업 갈림길 (깊이 24 → 17) | 43%만 닿음 → 나머지는 진로를 아예 못 정함 | 96% 닿음 + 못 닿은 사람은 청년 첫 차례에 고름 → **100% 정함** |
| 청년 둘째 결혼 지점 (31 → 25) | 38%만 닿음 | 82% |
| 중년 새 가족 칸 (입양·반려동물, 3 → 15) | 결혼 지점(13)보다 앞이라 **중년에 결혼한 사람은 입양 불가** (문서와 모순) | 결혼 지점 뒤로 옮김. 입양 5% → 13% |
| 학생 동아리 칸·두뇌 올림피아드 | 대학 갈림길을 앞당기느라 같이 앞으로 (9→6, 13→9) | |

### 기획엔 있는데 코드에 없던 것
- 백수: 매 턴 행복 +1
- 교사 방학(행복), 경찰·소방관 보람(행복)과 부상, 의사 밤샘 당직(행복↓), 개발자 승진 빠름
- 회사원 야근 카드 더 자주, **구조조정 카드** (공무원·교사·경찰·소방관은 무사)
- 과학자: 취업할 때 생명/화학 분야 고름 → 연구 성과가 그 주가를 올림
- 사업가: 창업할 때 분야 고름 → 회사가 크면 그 주가↑, 휘청이면↓
- 법적 공방: 돈이 있으면 변호사를 사서 유리
- 배우자 재력 높으면 가끔 집안 지원, 짠돌이는 매 턴 지출↓, 명품 중독은 매 턴 지출↑
- 반려동물 병원비가 사람 건강보험·의사 할인으로 처리되던 것 → 따로
- 반려동물 수명이 운세에 따라 조금씩 달라짐
- 휴식 칸·이벤트 길 대성공 때 가끔 찬스 카드
- **단계별 카드** (어린이: 칭찬 스티커·세뱃돈 / 학생: 시험 100점·알바 / 청년 / 중년: 건강검진 / 노년: 손주)
- 화면을 위로 밀어서 주사위 던지기, AI 속도 기본값 '빠르게'

## 2. 처음부터 끝까지 확인
- **사람이 아무 버튼이나 누르는 판 100판** (혼자 / 한 폰 2명 / 한 폰 4명, 1살부터 / 성인부터): 모두 끝까지 감, 멈춤 0, 숫자 깨짐 0, 능력치 0~10 유지
- **AI끼리 판 140판 이상**: 모두 끝까지
- 자동 테스트 16개 통과 (`cd app && npm test`)
- **실제 화면에서 한 판 끝까지** (성인부터, 나 + AI 3명, 버튼 자동 클릭): 청년 → 중년 → 노년 → 인생 결산까지, 화면 오류 0
  - 이때 찾아서 고친 것: 단계 마지막에 나이가 한 살 넘게 보임(청년 40세, 중년 60세) / 중년 취업 박람회에서 운동선수가 다시 될 수 있었음 (중년이면 은퇴하는 직업이라 막음)

## 3. 사용자 결정 (2026-10-15)
1. 친구 돈 소송에서 이겨도 **신용불량** → 반영
2. 중년 결혼식장 **뒤에는 데이트 칸 없음** (앞에만 둠), 지나면 소개팅 회사 자동 해지 → 반영
3. 결혼하자마자 **아이를 가질지 한 번 묻기** → 반영. 출산 13% → 42% (AI 기준)
4. (사용자 지적·확정) 대학/취업은 **학생 마지막 차례**에 고르고, 청년은 **출발점이 다름** (대학교 3차례 → 본 길 직업 칸 / 취업은 바로 직업 칸)
   - 영향 (AI 320명): 대학생이 3차례 늦게 출발해서 청년 둘째 결혼식장 86% → 41%, 둘째 상점 68% → 23%, 결혼 71% → 61%
5. (사용자 확정) "대가는 있지만 너무 크지 않게" → 청년 길 앞쪽으로 모음
   - 상점 7→5, 결혼식장 13→10, 축제 거리 16~24→11~17, 둘째 상점 28→18, 둘째 결혼식장 25→20, 취업 박람회 20→22
   - 결과 (본 길 기준): 둘째 결혼식장 대학 75% · 취업 97% / 둘째 상점 대학 87% · 취업 97% / 결혼 68% / 출산 33%

## (이전) 사용자가 정해야 할 것
1. **친구 돈을 안 갚고 소송에서 이기면 신용불량이 붙을까?** 06 문서에는 "안 갚은 사람은 신용불량", 동시에 "소송에서 이기면 안 갚아도 됨"이라 둘이 겹침. 지금 코드는 이기면 신용불량 없음(운세만↓)

3. **출산이 적음 (AI 기준 13%)**: 청년 결혼 뒤 데이트 칸에서만 낳을 수 있어서. 밸런스 단계에서 볼지, 규칙(예: 결혼 지점에서 바로 묻기)을 바꿀지
