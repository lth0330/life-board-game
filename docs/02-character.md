# 02. 캐릭터: 능력치와 직업

## 능력치
- **지력 / 체력 / 매력** 3개, 범위 0~10
- 운은 룰렛과 겹쳐서 능력치에서 뺌 (운세는 별도 상태 — `04-luck.md`)
- 어린 시절 선택(학원/놀기, 동아리 등)과 📈 성장 칸으로 자람
- 직업·조건 갈림길의 기준

## 직업 큰 틀
- 개수: 10~12개 정도
- 승진 있음
  - **꾸준형**: 월급 안정, 자동 승진 (회사원류)
  - **대박형**: 룰렛 결과에 따라 승진·추락 (연예·스포츠류)
- 조건을 못 채우면 **백수**로 시작. 월급 없음, 대신 행복 소폭 상승·능력치 키울 시간
- **전직**: 백수는 조건만 맞으면 아무 때나 취업. 직장인은 특정 칸(🛑 취업 박람회, 중년 이직·창업 갈림길)에서만
- 직업군별 혜택
  - 공무원 계열(공무원·경찰·소방관): 은퇴 후 **연금** → 노년기에 이득
  - 고소득·사회적 인정 직업(변호사·의사·운동선수 등): **높은 등급 배우자**를 만날 확률 상승
  - 사업가: **중년 창업으로만**. 대상: 퇴사한 직장인 / 빚낸 백수 / 일찍 은퇴하는 직업(운동선수 등)

## 직업 목록 초안 (세부 조건·특징은 5-1에서 다시 정함)

🎓 = 대학 필요

**꾸준형**
| 직업 | 조건 (초안) | 특징 (초안) |
|---|---|---|
| 회사원 | 지력 3 | 무난 |
| 공무원 | 지력 5 | 월급 낮음, 위기에 강함, 연금 |
| 교사 | 지력 5, 매력 3 🎓 | 행복 보너스 |
| 개발자 | 지력 6 | 중간 월급, 승진 빠름 |
| 경찰·소방관 | 체력 6, 지력 3 | 행복 보너스, 위험 이벤트, 연금 |
| 요리사 | 체력 4, 매력 3 | 창업 유리 |
| 변호사 | 지력 7, 매력 4 🎓 | 고소득 |
| 의사 | 지력 8 🎓 | 최고 소득, 바쁨(행복 약간 손해) |

**대박형**
| 직업 | 조건 (초안) | 특징 (초안) |
|---|---|---|
| 운동선수 | 체력 8 | 전성기 높고 은퇴 빠름 |
| 아이돌·배우 | 매력 8 | 대박 아니면 쪽박 |
| 유튜버 | 매력 5 | 문턱 낮고 변동 큼 |
| 사업가 | 중년 창업으로만 | 큰돈 아니면 빚 |
