# 인생게임 (웹)

기획은 `../docs/`. 이 폴더는 첫 시험판(프로토타입)이다.

- 실행: `npm install` → `npm run dev` → 브라우저에서 표시된 주소 (폰 크기로 보면 좋음)
- 테스트: `npm test` (AI 4명끼리 80판을 끝까지 돌려서 멈추거나 숫자가 깨지지 않는지 확인)
- 구조
  - `src/engine/` 게임 규칙 (화면과 분리. 나중에 3D 화면으로 바꿔도 그대로 씀)
    - `data.ts` 단계·직업·집·차·보험 등 숫자, `game.ts` 규칙, `ai.ts` AI 판단, `rng.ts` 난수
  - `src/ui/` 보드(판 안 시점, CSS 3D 흉내)와 시트(재테크·카드·사람들·결산)
  - `src/App.tsx` 시작 화면, 게임 화면, 진행
